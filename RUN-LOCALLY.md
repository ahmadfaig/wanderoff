# Run Wanderoff locally

Do not open `index.html` by double-clicking it. Browsers treat local files as isolated security origins, which prevents the Google Sheet connection from working reliably.

1. Double-click `start-local-server.bat`.
2. Open `http://localhost:8000` if it does not open automatically.
3. Keep the command window open while using the site.

To stop the local site, close the command window.
